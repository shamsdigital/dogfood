**Meta description:** Licensed general contractor for adaptive reuse across Middle Tennessee: converting existing buildings to new uses, including occupancy change and code upgrades. Call (615) 212-9005.
**H1:** Adaptive Reuse: Giving an Existing Building a New Life
**Display headline:** The hard part of reusing a building is everything you cannot see until you open it up.

Stellan Eoin Builders manages adaptive reuse as a licensed Tennessee general contractor (BC 73150). Adaptive reuse means taking a building that was made for one purpose and converting it to another. It is some of our favorite work, and some of the most demanding, because the existing structure sets the terms.

## What adaptive reuse involves
Converting a building from one use to another almost always means an occupancy change, which triggers code and life-safety upgrades: egress, accessibility, mechanical, and often structural work. The building rarely tells you everything until demolition begins, so the plan has to account for what is likely behind the walls.

## Why owners hire us for reuse projects
- **We have done it, more than once.** We converted a residential structure into The Moringa Tree, a health-focused café, and transformed a historic Nashville restaurant into The Bedford event venue. Both were full changes of use.
- **We plan for the unknowns.** RightStart is where we surface the probable surprises, structural, mechanical, and code, before you commit, so the budget accounts for them instead of being wrecked by them.
- **We respect what is worth keeping.** Reuse is often about preserving the character that makes the building worth saving while quietly bringing everything else up to current code.

## Planning first
Adaptive reuse projects run through RightStart, so the occupancy change, code path, and the realistic budget for the unknowns are established before you buy or sign. On a reuse project, that planning is the difference between a good deal and a money pit.

## Questions we hear most
**What is adaptive reuse?** It is converting an existing building from one use to another, for example a house into a café or a restaurant into an event venue. It usually involves an occupancy change and the code upgrades that come with it.
**Will a change of use trigger code upgrades?** Almost always. Changing occupancy typically requires egress, accessibility, and mechanical upgrades, and sometimes structural work. We plan for these up front.
**Can you tell me if a building is worth converting before I buy it?** Yes. That assessment is exactly what RightStart is for.

Historic projects come with constraints: what can be altered, what must be retained, which materials and methods are acceptable, and which review body signs off. The craft side matters too, matching original millwork, brick, and finishes so new work disappears into the old.

- **We work within the process.** Preservation projects answer to review standards and, often, a review body. We plan for that approval path rather than discovering it partway through.
- **Franklin and historic Nashville are familiar ground.** Middle Tennessee has real historic fabric, and we build within it.

Historic projects run through RightStart, so the preservation constraints, the approval path, and the true cost of period-appropriate work are settled before construction. Preservation surprises are expensive, so this planning matters more here than almost anywhere.

**Can you match original materials and details?** Yes. On historic work we match millwork, brick, and finishes so new construction reads as part of the original building.
**Do preservation projects take longer?** They can, because of the review and approval path and the care the work requires. We plan the schedule around that from the start rather than being surprised by it.
